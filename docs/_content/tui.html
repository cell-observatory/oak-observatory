The terminal app has three tabs: herdr · Observatory · Review (two, Observatory · Review, when it runs inside a herdr pane). Open it with oak to manage terminals, read conversations and decide captured edits.






  
  

  
  
  






Launching it


oak                 # the full dashboard
oak --tab review    # open on one tab: herdr, observatory or review
oak --session <id>  # pinned to one session
oak --once          # print one plain frame and exit (for a pipe or CI)
oak attach          # hand this terminal to herdr’s own client, with OAK in a pane



The tabs


  • herdr runs the terminal engine’s real client, including machines and agent permissions. Its own tab bar starts agents; OAK’s outer bar keeps the three fixed tabs.
    • 

  • Observatory joins live panes and unresolved history beside a pinned native conversation, with an explicit reply composer.
    • 

  • Review presents captured diffs and Keep / Undo decisions.


ctrl+a then n/p, or 1–3, switches tabs. ctrl+q twice quits from any tab, including while herdr owns the keyboard; ctrl+a then q twice does the same. ctrl+a twice sends one ctrl+a to the program in the herdr tab, where Claude Code and Codex both use it to go to the start of the line; otherwise the leader takes a plain key next, so ctrl+a ctrl+k does nothing.


Run oak doctor --fix to repair the required herdr setup. Use oak machine add build-box user@host to register a remote host.
