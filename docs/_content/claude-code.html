OAK captures Claude Code through local hooks and reads its native transcript outside the model loop. Capture adds no model tokens.

Setup

oak init
oak doctor --fix
oak agent start --kind claude

Install capture hooks with Claude Code closed, then open a new session. Before/after hooks preserve file changes for review; transcripts supply the conversation, actions and reasoning.

Terminal and review

herdr manages the agent terminal and its permission prompts. Observatory reads the conversation; Review decides captured edits. Claude Code sessions started outside herdr remain reviewable through their captured store, while prompt submission requires a matching live pane.

Codex also has native capture support. See Supported agents for the current integration scope.
