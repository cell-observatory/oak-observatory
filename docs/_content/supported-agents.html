OAK captures native Claude Code and Codex sessions through hooks and transcript parsing. herdr manages their terminals, state and remote machines.

Run oak doctor --fix to install the pinned herdr backend and its integrations. Start an agent in herdr or use oak agent start --kind claude or codex. Other terminals that herdr can run do not automatically gain OAK edit capture.
